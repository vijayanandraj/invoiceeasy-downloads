# invoiceeasy Desktop downloads

Offline billing and inventory for Indian small businesses.

## Download for Windows

[Download the latest Windows installer](https://github.com/vijayanandraj/invoiceeasy-downloads/releases/latest) · [All releases](https://github.com/vijayanandraj/invoiceeasy-downloads/releases)

Supports Windows 10/11, 64-bit. No GitHub account is required to download. Run the installer, then set up your shop on first launch. Node.js, Go and Python are not required.

The installer is unsigned, so Windows may display a publisher or SmartScreen warning. Each release includes SHA256SUMS.txt to verify the download.

## Features

- GST-aware invoices, quotations and POS with barcode search and keyboard shortcuts.
- Inventory, purchase imports, expenses and business reports.
- A4, 58 mm and 80 mm print layouts.
- Local SQLite database and backups; copy backups to a Google Drive for desktop folder.

Billing works offline. Google Drive backup syncing requires connectivity and Google Drive for desktop. Optional OCR tools are not bundled.

## Updating or starting fresh

Installing an update preserves your shop database. To start a fresh shop, use **File → Start a new shop**; the app backs up the current shop before creating an empty database.

This repository contains public installers and download information. Application source is maintained separately.
